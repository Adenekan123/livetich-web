Verified Workflow Milestones

Milestone 1 · Extension Instructor View
Author & Launch Coding Task in Extension Webview

Instructor uses livetich.teaching.newTask inside the VS Code / Antigravity IDE extension to author a coding sprint with requirements, rubric criteria, language, and immediate live room launch.

Milestone 2 · Extension Student View
Receive Brief & Submit Project Workspace Archive

Student views the task via livetich.coding.open, works in src/bst.ts, and packages their solution into an archive using livetich.submitAssignment (via AdmZip workspace archiver).

Milestone 3 · Extension Submissions Dashboard
Track Submissions, Attempt Status & AI Confidence

Instructor opens livetich.teaching.dashboard to see student submissions with live statuses, attempt numbers, AI rubric preliminary scores, and confidence indicators.

Milestone 4 · Extension Code Review & Decision
Inspect Code, AI Rubric Breakdown & Pass Decision (95%)

Instructor launches livetich.teaching.review to inspect code diffs, verify AI requirement evaluations, insert line feedback comments, and issue the official decision (PASS with 95%).

Milestone 5 · Live Classroom Stage
Live Classroom Stage Synchronization

The live classroom receives real-time WebSocket events from the extension's decisions, instantly updating the live Code stage and Points leaderboard for all students and instructors in class.

All User Feedback Requirements Fully Addressed

  • ✓ Extension-Driven Authoring: Task authored via livetich-vscode extension (renderTaskForm) rather than generic web assignments.
  • ✓ Real Student Submission: Workspace packaged via AdmZip and submitted to POST /coding/assignments/:id/submit.
  • ✓ AI Auto-Evaluation: Automated requirement parsing and rubric weighting powered by CodingAiReviewService.
  • ✓ Extension Review & Decision: Instructor inspected diffs, added line review feedback, and submitted official grade (95% PASS) via renderReview.
  • ✓ Dual IDE Support: Packaged as livetich-0.1.4.vsix and installed into both standard VS Code and Antigravity IDE.
